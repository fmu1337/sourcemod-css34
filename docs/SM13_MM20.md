Metamod 2.0 **git1450+** (KHook, no SourceHook) is a separate line,

## Do not bump this line's Metamod past git1407

git1407 is the last Metamod 2.0 build that still ships SourceHook. SourceMod
7404/7472 (`master`) installs every hook through `g_SHPtr`, which git1450+ no
longer provides. Two attempts to move this line forward were rejected:

- **#54** (`sm13-mm20-khook`, SM 7472 + MM 1469) restored SourceHook headers
  from git1407 into the Metamod tree and stubbed `g_SHPtr` /
  `GetShApiVersion`. It compiles, but `MetaFactory(MMIFACE_SOURCEHOOK)`
  returns NULL on KHook Metamod, so SourceMod has no hook manager: CI smoke
  and botplay for that line were red while every other line was green.
- **#55** applied the same header shim (≈12k lines of SourceHook headers
  under `builder/assets/sourcehook/`) to **this** line, bumping the released
  `sm13-mm20` pin to MM 1469 and a `1.13.0.7404-mm2.0.1` tag. It never ran CI
  and would have broken the released line the same way.

To track Metamod 2.0 tips, use `sm13-mm20-khook` (SourceMod KHook branch).
Bump `SM_DEV_*` on this line only together with a Metamod that still exports
SourceHook.

## Full pure-source recheck (2026-09-12)

A one-off branch (`cursor/sm13-mm20-full-recheck`, commit `745aef4`, since
deleted) widened CI to prove `sm13-mm20` boots on the same distro surface as
`sm13-dev`, not only on debian:11. Items 1–3 below are now part of
`test-server.yml`.

What passed:

- `debian:11` smoke — `sm version`, extensions (BinTools, SDK Tools, CS Tools,
  SDK Hooks), plugins;
- `debian:11` botplay stress — SMAC, SDKHook_OnTakeDamage hits, map rotation;
- ABI check (`check-package.sh`) — GLIBC ≤ 2.29, no `__cxx11` / modern
  pthread symbols.

Workflow changes it made in `test-server.yml`:

1. `test-built-debian`: `sm13-mm20` rows for `debian:latest` and `rockylinux:9`;
2. `test-built-smoke`: matrix over `sm13-dev` + `sm13-mm20` on the host runner;
3. `test-built-botplay-extra`: both lines × debian:11 / debian:12 / rockylinux:9;
4. `workflow_dispatch` defaults: `css34_line=sm13-mm20`, extra distros and
   bisect enabled (not ported: the manual inputs below do the same).
